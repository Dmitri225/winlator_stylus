# Что сделано по итогам независимой проверки

`SECURITY_REVIEW.md` — отчёт независимого рецензента по коду сборки `knox-build-12` (патчи 0001–0011). Текст отчёта не редактировался. Ниже — действия автора патчей после проверки.

| Находка | Статус | Что сделано |
| --- | --- | --- |
| F5 (запуск через оболочку) | Подтверждена и исправлена в `knox-build-13`, патч 0012 | В mksh (оболочка Android) значение вида `RANDOM=a[$(команда)]` действительно выполняло команду. Теперь оболочка только открывает дескриптор 9 и запускает `/system/bin/env`, переменные она сама не присваивает. Тест T6 на эмуляторе Android 15: значение не выполняется. |
| F6 (перезапись путей вне rootfs) | Проверено, изменений нет | Зашитый путь есть только в архивах, которые распаковываются в rootfs: `rootfs`, `rootfs_patches`, `box64`, графические драйверы, шаблон контейнера. В `pulseaudio.tzst` и компонентах Windows его нет. |
| F1 (ключ подписи в репозитории) | Не исправлено | Ключ с известным паролем лежит в репозитории. Устанавливать APK только из Releases своего форка. |
| F2, F3 (права токена и закрепление actions в CI) | Не исправлено | — |
| F4 (отладочная сборка) | Не исправлено | Унаследовано от исходников автора; отладку по USB держать выключенной. |
| F7, F8, F10, F11, F12, F13 | Не исправлено | Надёжность, не безопасность. |
