# Winlator 11.2 + S Pen

Официальный Winlator 11.2 с поддержкой S Pen, улучшенным сенсорным вводом и фоновой работой — для HoMM3/HotA на Galaxy S25 Ultra.

**Последняя сборка:** [Winlator_11.2_SPen_9.apk](https://github.com/Dmitri225/winlator_stylus/releases/download/spen-11.2-build-9/Winlator_11.2_SPen_9.apk) (157 МБ). Все сборки — в [Releases](https://github.com/Dmitri225/winlator_stylus/releases) с тегами `spen-11.2-build-N`.

## Как устроена ветка

- GitHub Actions берёт исходники [brunodev85/winlator-app](https://github.com/brunodev85/winlator-app) @ `a030f55` — коммит, на который официальный [brunodev85/winlator](https://github.com/brunodev85/winlator) ссылается как на релиз 11.2.
- Накладывает патчи из `patches/` (`0001`–`0008`), собирает APK и подписывает ключом из `ci/`.
- Сравнивает каждый файл APK с официальным `Winlator_11.2.apk` по SHA-256 и прикладывает отчёт `APK_COMPARISON.md` к релизу.
- `verify-install.yml` — проверка подписи и установки на эмуляторе Android 15 (запускается изменением `ci/verify-tag.txt`).
- Изменения только в README и проверочных файлах сборку не запускают.

Все сборки 11.2 подписаны одним ключом и ставятся поверх друг друга без удаления. Официальный Winlator (в том числе в Защищённой папке Knox) нужно удалить: имя пакета то же (`com.winlator`), подпись другая.

## Ввод

| Действие | Перо | Палец |
| --- | --- | --- |
| Наведение | Курсор следует за пером (точка Samsung скрыта) | — |
| Короткое касание | ЛКМ в точке касания | Курсор под палец, затем ЛКМ |
| Удержание без движения | ПКМ до отрыва + вибрация | ПКМ до отрыва + вибрация |
| Перетаскивание | ЛКМ с точки касания или прокрутка карты | Тачпад |

| «Ластик» пера | Средняя кнопка | — |

## Исправленные ошибки автора

- «Полный экран»: касания пересчитывались одинаково по осям и не обновлялись при переключении — курсор не совпадал с пером.
- Смена тёмной темы, шрифта, языка или SIM пересоздавала экран игры и останавливала Wine.

## Настройки для HoMM3/HotA и телефона

- Контейнер: WineD3D → рендерер **GDI**; HD-лаунчер HotA: **GDI 32 resizeable** (иначе чёрный экран).
- Параметры разработчика → «Отключить ограничения дочерних процессов»; Winlator — в «никогда не спящие приложения»; автоперезагрузку отключить.
- Play Защита предупреждает при установке (target 28, как у официального Winlator) — «Все равно установить».

## Ограничения

- Автоматических тестов ввода нет; на устройстве сборки проверяет владелец.
- Шаг прокрутки по умолчанию 32 пикселя на клетку (меняется ползунком); в режиме прокрутки ползунки игры двигаются кликами.
- Растягивание экрана — для окна игры без рамки, меньшего, чем экран контейнера.
- «Не приостанавливать в фоне» расходует батарею, звук продолжает играть.
